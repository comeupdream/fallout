# Vault 180

Pip-Boy-styled supply ledger for a two-adult, 180-day winter grid-down plan.
Open `index.html` — a phosphor-terminal checklist of every item in the plan,
organized by acquisition tier, with check-off tracking (synced when running as
a claude.ai artifact; localStorage when opened as a plain page).

- `index.html` — the ledger app (single file, no build step; GitHub-Pages ready)
- `preparedness/six-month-winter-plan.md` — the full written plan: ration model,
  basement layout, water stack, heat/fuel with safety rules, budget, 180-day thesis
- `preparedness/ledger.md` — the purchase ledger of record (lean build active)

Plan headline numbers: ~1.03M calories at full build, 500 gal stored water +
four-layer purification, lean build ≈ $10,700.
